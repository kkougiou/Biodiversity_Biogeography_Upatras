Quantifying Biodiversity

The α, β, γ Framework

Following1:

\[ \gamma = \alpha \times \beta \]

Component Scale R function
α (alpha) Local richness vegan::specnumber()
β (beta) Turnover among sites betapart::beta.pair()
γ (gamma) Regional richness vegan::specpool()

Hill Numbers — A Unified Framework

\[ {}^{q}\!D = \left( \sum_{i=1}^{S} p_i^{\,q} \right)^{1/(1-q)} \]

  • (q = 0): species richness
  • (q = 1): exponential of Shannon entropy
  • (q = 2): inverse Simpson concentration
library(iNEXT)
out <- iNEXT(community_data, q = c(0, 1, 2),
             datatype = "abundance", endpoint = 500)
ggiNEXT(out, type = 1) + scale_color_viridis_d(option = "D")

β-Diversity: Turnover vs Nestedness

2 decomposed Sørensen β into two components:

\[ \beta_{\text{SOR}} = \beta_{\text{SIM}} + \beta_{\text{SNE}} \]

library(betapart)

# Convert abundance to presence/absence
pa <- ifelse(BCI > 0, 1, 0)

# Pairwise multi-component beta
bp <- beta.pair(pa, index.family = "sorensen")

# Mean values
sapply(bp, mean)
#>  beta.sim  beta.sne  beta.sor
#>      0.41      0.06      0.47

Species Distribution Modelling

SDM Workflow

flowchart LR
  A[Cleaned<br/>occurrences] --> C[Predictor<br/>selection]
  B[Environmental<br/>layers] --> C
  C --> D[Pseudo-absences<br/>or background]
  D --> E[Model fitting]
  E --> F[Spatial<br/>cross-validation]
  F --> G[Prediction &<br/>uncertainty]

Predictor Selection — Multicollinearity

library(usdm)

# Variance Inflation Factor stepwise selection
v <- vifstep(bio_gr, th = 5)
v
#> 4 variables from 19 input variables have collinearity problem:
#>   bio6 bio11 bio16 bio17

# Keep only retained predictors
preds <- bio_gr[[v@results$Variables]]

A VIF threshold of 5–10 is common; lower is stricter.

Fitting a MaxEnt-style Model

library(predicts)

# MaxEnt via the `predicts` package (successor of `dismo`)
mod <- MaxEnt(
  x = preds,
  p = st_coordinates(pts_thin),
  removeDuplicates = TRUE
)

# Predict habitat suitability
suit <- predict(preds, mod, type = "cloglog")
plot(suit, col = viridis(100), main = "Habitat suitability")

Spatial Block Cross-Validation

library(blockCV)

sb <- cv_spatial(
  x         = pts_thin,
  column    = "occ",
  k         = 5,
  size      = 50000,   # 50 km blocks
  selection = "random",
  iteration = 100
)

cv_plot(cv = sb, x = pts_thin)

Random CV inflates SDM performance by exploiting spatial autocorrelation. Always use spatial blocking for honest evaluation.

Biogeographical Regionalisation

From β-Diversity to Bioregions

The workflow:

  1. Build a site × species matrix on a regular grid
  2. Compute pairwise β-diversity (betapart)
  3. Apply hierarchical clustering (hclust)
  4. Cut the dendrogram → bioregions
  5. Map back to space

See3 and4 for ecoregion delineation methods.

Gridded β-Diversity in R

# Build a 0.5° grid
grid <- st_make_grid(greece, cellsize = 0.5, square = TRUE) |>
        st_as_sf() |>
        mutate(cell_id = row_number())

# Join occurrences to grid
sp_grid <- st_join(all_species_pts, grid)

# Site × species matrix
mat <- sp_grid |>
  st_drop_geometry() |>
  count(cell_id, species) |>
  pivot_wider(names_from = species, values_from = n,
              values_fill = 0) |>
  column_to_rownames("cell_id")

# Presence/absence + Simpson dissimilarity
pa  <- ifelse(mat > 0, 1, 0)
dis <- beta.pair(pa)$beta.sim
hc  <- hclust(dis, method = "average")
clusters <- cutree(hc, k = 5)

Mapping Bioregions

grid_clust <- grid |>
  filter(cell_id %in% rownames(mat)) |>
  mutate(region = factor(clusters))

ggplot() +
  geom_sf(data = greece, fill = "grey95") +
  geom_sf(data = grid_clust, aes(fill = region),
          color = NA, alpha = 0.85) +
  scale_fill_viridis_d(option = "D", name = "Bioregion") +
  labs(title    = "Biogeographical regionalisation of Greece",
       subtitle = "Based on Simpson β-diversity (turnover)",
       caption  = "Data: GBIF · CRS: EPSG:4326") +
  theme_void()
